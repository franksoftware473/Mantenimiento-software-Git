# Historias de usuario - MoviCampus

## HU01. Inicio de sesión
Como estudiante, quiero iniciar sesión en la aplicación
para acceder a las funcionalidades disponibles.

## HU02. Consulta de rutas
Como estudiante, quiero consultar las rutas disponibles
para conocer las opciones de transporte.

## HU03. Consulta de horarios
Como estudiante, quiero consultar los horarios
para organizar mis desplazamientos.

## HU04. Reportar novedades
Como estudiante, quiero reportar novedades del servicio
para informar sobre problemas del transporte.

## HU05. Consultar notificaciones
Como estudiante, quiero consultar notificaciones
para conocer avisos y novedades importantes.
